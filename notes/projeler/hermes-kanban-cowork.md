# Kanban (Dispatch) + Cowork — 03.10.2026

## Kanban (Dispatch)
- **Nədir:** Task idarəetmə sistemi. Tasklar yaratmaq, worker-lara təyin etmək, nəticəni izləmək üçün
- **Qurulum:** `hermes kanban init` — DB yaradıldı (`~/.hermes/kanban.db`)
- **Dispatcher:** Gateway daxilində aktivdir (`kanban.dispatch_in_gateway: true`), hər 60 san yoxlayır
- **Board:** Default (boş)
- **Worker:** "default" profili var
- **Dashboard:** YOXDUR — CLI və agent üzərindən idarə olunur
- **Status:** Qurulub, aktiv, istifadə edilmir. User lazım olanda deyəcək

## Cowork (Computer Use)
- **Nədir:** Hermes-in desktop-u arxa planda idarə etmə qabiliyyəti (klik, yazı, scroll)
- **Status:** Toolset aktivdir, hələ işlədilmir
- **Platformalar:** macOS, Windows, Linux

## Nəticə
Hər ikisi aktivdir, amma hələ istifadə edilmir. User ehtiyac olanda xəbərdar edəcək.
